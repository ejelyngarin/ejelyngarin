EJELYN GARIN PORTFOLIO — FINAL POPUP BUILD

This build includes the full portfolio website and its images.

Pages 2–4:
- About Me: dashboard cards open the corresponding complete content section.
- Achievements: dashboard cards open the relevant content; the gallery opens category collections and individual images in a larger viewer.
- Parents: the family section displays the family portraits and the letter buttons open the complete family letters.

Popup behavior:
- Close button, clicking the dark backdrop, or Escape closes the dashboard popup.
- Main dashboard pages are fixed/non-scrolling. Long popup content can scroll inside the popup so no text or photos are clipped on smaller screens.
- Achievement gallery images use the gallery's own enlarged image viewer. Family and other inline photos use the photo viewer.

DEPLOYMENT
1. Keep a backup of your current project folder.
2. Extract this ZIP.
3. Replace the contents of your GitHub repository with the extracted project files, keeping the same folder structure.
4. Commit and push to the production branch connected to Cloudflare Pages.
5. Wait for the Cloudflare deployment to finish, then hard-refresh the website (Ctrl+Shift+R / Cmd+Shift+R).

IMPORTANT
Open the site through its hosted URL or a local web server (for example VS Code Live Server), not by opening an individual HTML file in a restricted file preview. The site uses relative CSS, JavaScript, and image paths.
