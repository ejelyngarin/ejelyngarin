# Ejelyn C. Garin — Personal Academic Portfolio

## Pages
- `index.html` — Home
- `personal.html` — About Me (Page 02; clickable cards and pop-up details)
- `achievements.html` — Achievements and category-first photo gallery
- `parents.html` — Interactive family tribute

## Project structure
- `css/style.css` — shared and page-specific styles
- `js/script.js` — navigation and page search
- `js/about-interactions.js` — About Me pop-up content
- `js/interest-modal.js` — interest cards and resource pop-ups
- `js/family-letters.js` — family tribute pop-ups
- `js/gallery.js` — achievement gallery entries and behavior
- `images/` — profile, family photos, school logos, and achievement photos

## Achievement gallery images
Place image files inside `images/` and register each image in `js/gallery.js` using its exact filename. The browser does not automatically display every file in the folder. Use browser-compatible image formats such as `.jpg`, `.jpeg`, or `.png`.

## Publishing
This project is a static website and can be hosted using GitHub Pages or another static hosting service. Configure the custom domain and DNS records with the domain provider's current instructions. If the instructor requires `www`, configure the `www` hostname and verify HTTPS after DNS propagation.
